# User Segmentation Analysis using RFM

## 📌 Overview

Customer segmentation analysis using the **RFM (Recency, Frequency, Monetary)** method to identify customer behavior and purchasing patterns.

## 🎯 Objectives

* Calculate customer RFM metrics
* Assign RFM scores
* Segment customers based on purchasing behavior
* Identify valuable and at-risk customer segments

## 🛠️ Tools

* Python
* Pandas
* NumPy
* SciPy
* Matplotlib
* Google Colab

## 📊 RFM Segments

The analysis resulted in 10 customer segments:

* Champion
* Loyal Customers
* Potential Loyalists
* Can't Lose Them
* Need Attention
* New Customers
* Promising
* At Risk
* About to Sleep
* Hibernating

## 🔍 Key Findings

* **Hibernating** is the largest segment with **1,056 customers (27.2%)**.
* **Champion** consists of **553 customers (14.2%)** and has the highest purchase frequency and average order value.
* **At Risk** consists of **418 customers (10.7%)** who previously purchased frequently but have been inactive for a long period.
* **Can't Lose Them** has relatively high customer value despite having low customer volume.


## 💡 Recommendation

Focus on **reactivation campaigns** for Hibernating and At Risk customers, while maintaining **loyalty programs** for Champion and Loyal Customers.
